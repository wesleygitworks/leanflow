# 🏆 LeanFlow — Sistema Inteligente de Gestão Lean

## 🚀 Visão Geral
O **LeanFlow** une **tecnologia e filosofia Lean** em um ambiente digital prático.  
Desenvolvido para **organizar, educar e impulsionar** a melhoria contínua em empresas — mesmo para não programadores.

Inspirado na **Indústria 4.0**, é uma ferramenta operacional que aplica o pensamento enxuto à gestão de processos.

---

## 🎯 Finalidade Principal
**4 Pilares Integrados:**
- 📝 **Registro** de sugestões de melhorias  
- 📊 **Gestão** de processos Lean (Kaizen, PDCA, 5S)  
- 🎓 **Capacitação** via chatbot educativo  
- 📋 **Relatórios automáticos** para DDS e performance  

---

## 💼 Para Quem Serve?
- ✅ **PMEs** - Ideal para iniciar cultura Lean  
- ✅ **Grandes empresas** - Como ferramenta complementar  
- ✅ **Indústrias & Serviços** - Adaptável a qualquer setor  

**Problemas Resolvidos:**
- Sugestões centralizadas e organizadas
- Processos Kaizen padronizados  
- Colaboradores educados sobre Lean
- Relatórios automáticos (economia de 4h/semana)

---

## 🛠️ Tecnologia & Inovação
- **Linguagem:** Python + Tkinter  
- **Banco:** SQLite  
- **Relatórios:** PDF/CSV automáticos  
- **Chatbot:** 11 módulos educativos Lean

**✨ Diferencial:** Desenvolvido com **DeepSeek AI** - prova de como a IA acelera soluções reais para problemas empresariais.
